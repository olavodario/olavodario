## Projetos em Destaque

### 🤖 [AICommit](https://github.com/olavodario/aicommit) — CLI com IA para Git
> **Python · Google Gemini API · CLI**

Ferramenta de linha de comando que usa IA para gerar mensagens de commit automaticamente no padrão **Conventional Commits**, analisando o `git diff --staged`. O usuário revisa a sugestão antes de confirmar — rápido, padronizado e plugável com outras APIs de IA.

- Integração com Google Gemini via API
- Padrão Conventional Commits para histórico limpo
- Configurável para outros modelos de IA (basta trocar a biblioteca)
- Disponível como comando global via PATH

---

### 👤 [CRUD-Usuarios](https://github.com/olavodario/CRUD-Usuarios) — Sistema de Autenticação em Java
> **Java · NetBeans · POO**

Sistema de gerenciamento de usuários com autenticação por senha, desenvolvido para praticar **orientação a objetos e estruturação de projetos Java**. Cobre o ciclo completo de criação, leitura, atualização e exclusão de registros com controle de acesso.

---

### 🗳️ [UrnaJava](https://github.com/olavodario/UrnaJava) — Urna Eletrônica com Interface Gráfica
> **Java · JPanel · Swing**

Simulação de urna eletrônica com interface gráfica construída em JPanel/Swing. Implementa lógica de votação, apuração de votos e exibição de resultados.

---

### 🌡️ [HVAC-FLOW](https://github.com/olavodario/HVAC-FLOW) — Ferramenta para o Setor HVAC
> **TypeScript**

Projeto nascido da minha experiência diária no setor de climatização. Construído para resolver um problema real de fluxo de processos técnicos — aplicação prática de desenvolvimento de software em domínio de negócio específico.

---

### 🖥️ [EduSPAManager](https://github.com/olavodario/EduSPAManager) — Sistema de Gerenciamento de Alunos
> **PHP · JavaScript · MariaDB · HTML/CSS**

CRUD completo para gerenciamento de alunos com frontend em SPA e backend em PHP integrado ao MariaDB. Primeiro projeto fullstack com separação clara de responsabilidades entre front e back.
