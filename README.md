### 💡 Sobre mim

Estudante de **Engenharia de Software (UNAERP)** e técnico em **ADS (ETEC)**. Desenvolvo aplicações web completas com foco principal em **Backend, arquitetura limpa e segurança desde o design (*Secure Coding*)**.

Não programo apenas para o código funcionar: busco entender o problema de negócio, estruturar APIs escaláveis, modelar bancos de dados eficientes e garantir que a aplicação seja segura e fácil de manter.

- 🔭 **Foco atual:** Java, Spring Boot, TypeScript, Node.js, PostgreSQL e Docker.
- 🔐 **Diferencial:** Estudo contínuo em *Application Security* (OWASP, autenticação e autorização).
- 🎯 **Objetivo:** Atuar como **Desenvolvedor Full Stack ou Backend (Estágio / Júnior)** em projetos reais.
